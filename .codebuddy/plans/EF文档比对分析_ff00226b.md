## 产品概述

对 EF 文件夹中的两份文档进行系统性比对分析：Word 文档（HF 4.0 产品介绍精简版 v0.1，完整权威来源）与 PDF 文档（hf.pdf，精炼版本），验证 PDF 是否准确反映了 Word 中的核心定义，检查是否存在错误、篡改或关键内容遗漏，最终输出一份结构化的比对结论 markdown 文档。

## 核心功能

- 完整提取 Word 文档和 PDF 文档的文本内容
- 按 7 篇章节结构逐篇比对，覆盖：章节完整性、定义准确性、数据一致性、关键概念保留、错误检测、精炼合理性六个维度
- 输出 md 文档，包含：总体结论、逐篇比对明细、错误清单、遗漏清单、改进建议

## 技术方案

### 环境与依赖

- **Python 3.14.7**（已安装）
- **pypdf**（需安装）：用于 PDF 文本提取，纯 Python 实现，安装简单、兼容性好
- Word 文档无需额外库：.docx 本质是 ZIP 包，用 Python 内置 `zipfile` 读取 `word/document.xml`，正则剥离 XML 标签即可得到纯文本

### 实现策略

1. **Word 文本提取**：用 `zipfile` 打开 docx → 读取 `word/document.xml` → 正则 `re.sub(r'<[^>]+>', '\n', xml)` 剥离标签 → 按段落整理。前期探索已验证此方法可行，成功提取了前 80 行文本（产品定位、级别体系、核心叙事等内容）

2. **PDF 文本提取**：`pip install pypdf` → 用 `pypdf.PdfReader` 逐页提取文本。需注意文件名 `hf​.pdf` 中 h 和 f 之间含零宽字符 U+200B，用 `glob` 或 `os.listdir` 匹配实际文件名而非硬编码路径

3. **比对方法**：

- 先提取 Word 全文，建立 7 篇章节的结构索引（第一篇~第七篇）
- 再提取 PDF 全文，按相同方式建立结构索引
- 逐篇匹配：结构对齐 → 定义核对 → 数据核对 → 概念核对
- 重点核对项：年龄段（7-9岁）、CEFR 级别（Pre-A1 到 A2.2）、5 个级别名称、剑桥考试对标、单元数量、课时配置、双体系定义（应用能力+应试能力）、战略前置叙事

4. **输出**：将比对结论写入 `EF文档比对分析报告.md`，结构包含总体评价、逐篇明细表、错误/遗漏清单

### 执行注意事项

- PDF 文件名零宽字符：用 `os.listdir()` 获取实际文件名，不硬编码字符串
- Word XML 中文本可能被分段拆开（如"产\r\n品介\r\n绍"），需合并相邻文本节点
- PDF 中中文文本可能存在编码问题，用 `errors='replace'` 处理
- 两份文档体量差异大（Word 130KB vs PDF 3.25MB），PDF 较大可能含图片，文本提取后需排除图片相关噪音
- 比对时关注"精炼版"的特性：合理删减细节不算遗漏，但核心定义、关键数据、重要概念的缺失或错误必须标记
